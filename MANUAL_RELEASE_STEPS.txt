================================================================================
TROUBLESHOOTING
================================================================================

Q: "git status" shows files modified?
A: Run: git checkout .   (discards all local changes)

Q: "git commit" says index.lock exists?
A: Run: sleep 5 && git commit -m "..."
   Or: Close any git GUI apps and retry

Q: Tests fail during "release.sh"?
A: The script output will show which test failed
   Fix the issue: git add . && git commit -m "fix"
   Re-run: ./scripts/release.sh minor

Q: release.sh says "FAIL: working tree dirty"?
A: This script checks before running, so:
   1. Run: git status
   2. See what's uncommitted
   3. Either: git add . && git commit -m "..."
             Or: git checkout . (if you don't want the changes)
   4. Re-run: ./scripts/release.sh minor

Q: Need to rollback?
A: git checkout v3.3.0
   ./scripts/tp install v3.3.0
