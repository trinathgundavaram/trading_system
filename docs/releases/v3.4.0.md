# Release v3.4.0 - Dynamic Position Sizing (2026-07-27)

Position size now scales automatically with portfolio growth.

## Configuration
```yaml
trading:
  use_dynamic_sizing: true
  position_size_pct_of_portfolio: 3.0
```

## Example
- $60 portfolio → $1.80 per trade
- $300 portfolio → $9.00 per trade
- Scales automatically as portfolio grows

## Installation
./scripts/tp install v3.4.0

See DYNAMIC_SIZING.md for details.
